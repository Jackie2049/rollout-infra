2.28M模型 300步 FP32, 扫描7个σ值(0, 0.001, 0.005, 0.01, 0.05, 0.1, 0.5)

## 关键发现

### 1. 噪声的Inverted-U曲线 (Goldilocks Zone)

```
eval(σ) 呈倒U形:

42%  ← σ=0 (无噪声,困住)
48%  ← σ=0.001 (太小)
77%  ← σ=0.005 (开始有效)
100% ← σ=0.01 (最优!)
100% ← σ=0.05 (仍最优!)
88%  ← σ=0.1 (过度)
59%  ← σ=0.5 (严重过度)

→ 理论解释:
  σ太小: 梯度噪声<local optima深度 → 无法逃离 → 困住
  σ最优: 梯度噪声≈local optima深度 → 逃离local → 发现全局最优 → 100%!
  σ太大: 梯度噪声>信号强度 → 梯度方向被随机噪声淹没 → 无法精确收敛

→ 与模拟退火(Simulated Annealing)类比:
  SA温度T → 我们的σ
  T太低 → 困住 → σ=0 (42%)
  T适中 → 探索+收敛 → σ=0.01 (100%)
  T太高 → 随机游走 → σ=0.5 (59%)

→ 但我们的噪声不需要退火! 固定σ=0.01全程最优!
  → 因为SGD+AdamW已有自适应学习率(v∝Σg²)
  → AdamW在参数接近最优时自动减小更新幅度 → 相当于隐式退火!
  → 外加固定噪声σ=0.01 → AdamW处理精确方向,噪声处理探索 → 完美配合!
```

```
50   | 24%    | 36%    | 36%    | 14% ← σ=0.5反而下降!

→ σ=0.01: 每个checkpoint稳步上升(2→24→34→52→56→76→100) → 一致性最好!
→ σ=0.05: 早期更快(50步:36% vs σ=0.01:24%) → 但中后期稍慢

→ σ=0.5: 起始高但增长慢 → 噪声太大,每步进步小

→ σ=0.01是最佳平衡: 稳定轨迹 + 100%最终结果
→ σ=0.05也100% → 5x噪声仍能收敛 → 说明2.28M模型相当鲁棒!
```

### 4. 噪声与AdamW的协同

```
为什么固定噪声σ=0.01不需要退火?

AdamW更新: θ -= lr × m / (√v + ε)

v = EMA of g² → 梯度大的参数 → v大 → 更新幅度小 (自动退火!)
m = EMA of g → 梯度方向平滑 → momentum → 方向一致

噪声 + AdamW:
  1. 噪声给每步添加随机扰动 → 探索
  2. AdamW momentum平滑方向 → 即使有噪声,长期方向一致
  3. AdamW v自适应调整幅度 → 参数接近最优时更新变小 → 精确收敛
  4. clip_grad_norm(max_norm=1.0) → 防止噪声导致的梯度爆炸

→ 噪声(探索) + AdamW(收敛) + clip(稳定) = 三者协同!
→ 这就是为什么σ=0.01固定噪声能从2%到100% → 稳步上升不退火!

→ 与GRPO σ归一化的连接:
  GRPO A=(r-μ)/σ → advantage magnitude ∝ 1/σ_group
  → σ_group小(组reward一致) → advantage大 → 梯度强 → 更多更新 → 但方向精确
  → σ_group大(组reward分化) → advantage标准化 → 梯度温和 → 但方向来自reward对比

  → GRPO σ归一化 ≠ 纯噪声,而是:
    自适应幅度控制(σ) + reward方向选择(A) + momentum平滑(AdamW)
    → 三重机制 → 比纯噪声更精密!
```
