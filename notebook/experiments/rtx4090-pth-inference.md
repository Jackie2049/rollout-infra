# RTX 4090 PyTorch 推理 Benchmark

> 2026-06-05 | RTX 4090, PyTorch 2.9.0+cu128
> 模型: 4 层 Transformer (H=4096, 32 heads, ~891M params), 按比例外推到 7B

## 配置

- **模型**: 4 层 Transformer, hidden=4096, 32 heads, FFN=11008, vocab=32000
- **参数量**: 891.4M (FP16, 1782.7 MB)
- **外推**: 32 层 = 8x 延迟, 即 7B 模型

## Exp1: Prefill 延迟

| SeqLen | 延迟 (ms) | TFLOPS | tok/s |
|--------|-----------|--------|-------|
| 64 | 2.05 | 55.6 | 31,194 |
| 128 | 2.19 | 104.2 | 58,477 |
| 256 | 2.91 | 157.0 | 88,072 |
| 512 | 5.53 | 165.1 | 92,639 |
| 1024 | 10.58 | 172.5 | 96,766 |
| 2048 | 21.13 | 172.8 | 96,903 |
| 4096 | 45.59 | 160.2 | 89,837 |

**分析**:
- 峰值 ~173 TFLOPS @ S=2048 (compute-bound, 接近硬件极限)
- S≤256 未饱和 (TFLOPS 低, kernel launch 占比大)
- S=4096 略降 (可能 L2 cache 压力)

**外推到 7B**: S=1024 → ~85ms, ~12K tok/s

|-------|-----------|-------|--------|
| 1 | 1.761 | 568 | 1.0 |
| 2 | 1.791 | 1,117 | 2.0 |
| 4 | 1.799 | 2,224 | 4.0 |
| 16 | 1.839 | 8,698 | 15.5 |
| 32 | 1.942 | 16,478 | 29.4 |
| 64 | 2.140 | 29,913 | 53.3 |
| 128 | 2.359 | 54,270 | 96.7 |
| 256 | 3.318 | 77,164 | 137.6 |

**分析**:
- Batch=1 仅 568 tok/s (利用率 <1%)
- B=1→64: 延迟几乎不变 (1.76→2.14ms), 吞吐线性增长
- B=256: 77K tok/s, 137.6 TFLOPS

**外推到 7B**: B=128 → ~19ms, ~6.8K tok/s

## Exp3: SDPA vs Naive

| SeqLen | SDPA (ms) | Naive (ms) | Speedup |
|--------|-----------|------------|---------|
| 128 | 0.447 | 0.472 | 1.06x |
| 256 | 0.614 | 0.643 | 1.05x |
| 512 | 1.157 | 1.221 | 1.06x |
| 1024 | 2.240 | 2.762 | 1.23x |
| 2048 | 4.584 | 6.756 | 1.47x |

**分析**:
- 单层 Attention: SDPA 在 S≥1024 时优势明显 (1.23-1.47x)
- 完整模型 SDPA 加速比更高 (因为 FlashAttention O(N) 内存 vs O(N²))
- S≤512: 加速小 (序列太短, SDPA overhead 占比大)

## 7B 模型估计 (RTX 4090)

基于 8x 外推 (4层→32层):

| 场景 | 延迟 | 吞吐 |
|------|------|------|
| Prefill S=1024 | ~85ms | ~12K tok/s |
| Prefill S=2048 | ~169ms | ~12K tok/s |
| Decode B=1 | ~14ms | ~71 tok/s |
| Decode B=32 | ~16ms | ~2K tok/s |
| Decode B=128 | ~19ms | ~6.8K tok/s |
| Decode B=256 | ~27ms | ~9.6K tok/s |

**对比 A16 (实测)**:
- 7B decode: A16 ~8 tok/s @ B=1, 4090 ~71 tok/s (**8.9x**)
- 这与 HBM BW 比例一致 (890 vs 76 GB/s = 11.7x, 但模型更大可用 VRAM 少)

## 关键结论

1. **Prefill 是 compute-bound**: 173 TFLOPS, 接近 RTX 4090 理论极限
2. **Decode 是 memory-bound**: B=256 达到 137 TFLOPS (模型权重重复利用)
3. **Batch=1 浪费严重**: 568 tok/s vs B=256 的 77K tok/s (136x!)
4. **7B on 4090**: 预估 ~14 GB 模型, ~10 GB KV Cache (可服务数百并发)
5. **SDPA 加速随序列增长**: S=2048 时 1.47x per layer
