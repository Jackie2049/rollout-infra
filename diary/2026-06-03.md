## 22:50 — vLLM Prefix Caching V1 源码分析完成

后台 agent 完成了 vLLM V1 prefix caching 深度分析。关键发现:
- Hash chain 机制: 每个block 的 hash 依赖 parent hash + tokens + extra_keys
- 四种 attention 类型有不同的 cache hit 检测策略 (FullAttention 左→右, SlidingWindow 右→左)
- Block 生命周期: allocate → hash → cache → reuse (touch) → free → evict
- V1 新增: Hybrid KV Cache, EAGLE/MTP 支持, 更好的 metrics

保存为 `notebook/projects/vllm-prefix-caching-v1.md`
