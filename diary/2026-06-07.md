## 17:40 — Fused RMSNorm Backward CUDA Kernel 实现

### Python Fallback Backward Bug 修复

发现并修复 Python fallback backward 的关键 bug:
- **Bug**: `grad_input = grad_output * weight * inv_rms + grad_output - x_norm * coeff` 中 `+ grad_output` 是错误的
- **原因**: `y = x_norm * w + r` 中, `x` 只通过 `x_norm * w` 路径出现, residual 分支不贡献 `d_x`
- **修复后公式**: `d_x = inv_rms * (dy * w - x_norm * mean(dy * w * x_norm))`
- **验证**: FP32 backward correctness ALL PASS (dx_diff < 1.43e-6, cos_sim = 1.0)

### CUDA C++ Backward Kernel 实现 (v5)

新增 6 个 backward kernel (FP32/FP16/BF16 × add/norm):
- **设计**: 1 warp/row, 3-pass (inv_rms→dot/dw/dr→dx), atomicAdd for dw, FP32 accumulation→dtype convert
- **数学**: `d_x = inv_rms * (dy*w - x_norm*coeff)`, `d_r = dy`, `d_w = Σ(dy*x_norm)`
- **Host**: `fused_rms_norm_add_backward` 返回 (dx, dr, dw), `fused_rms_norm_backward` 返回 (dx, dw)
- **编译**: RTX 4090, sm_89, `python setup.py build_ext --inplace`

### vLLM V1 Triton Attention Kernel 深度阅读

- **两套Triton attention**: Split-KV(SGLang origin, MLA/TurboQuant专用) vs Unified(IBM origin, TritonBackend主后端)
- **Decode算法本质**: 分段online softmax → 全局reduce, 数学等价FlashAttention
- **Unified kernel**: 2D(prefill/大batch) vs 3D(小batch decode, 16 segments)
- **3D threshold**: batch ≤ 128/num_kv_heads → 3D mode; 大batch → 2D mode
- **GQA BLOCK_M优化**: 打包多个Q头到一个block → KV加载↓87.5%
- **FP8 per-token-head quant**: scale融合到tl.dot后→ 减少87.5% S tile计算
- **Sliding window**: tile pruning只遍历window范围 → 跳过无关tile
- **功能**: ALiBi/Sinks/MM Prefix/Chunked/Softcap/4 quant modes
- 笔记: `vllm-v1-triton-attention-kernel-deep.md`

### vLLM V1 Cascade Attention 深度阅读

- **算法**: Prefix(共享,bidirectional)+Suffix(私有,causal) → LSE rescale合并
- **触发**: prefix≥256 tokens, requests≥8, 无ALiBi/SWA, 非DCP
- **FlashAttn实现**: cascade_attention() → prefix FA + suffix FA + merge_attn_states
- **FlashInfer**: MultiLevelCascadeAttentionWrapper(2层) 但**当前被禁用**
- **Triton**: 不支持cascade (metadata有字段但use_cascade=False)
- **数学**: LSE merge等价于全序列softmax (精确无误)
- **vs SGLang**: vLLM整个batch共享prefix(更激进), SGLang每请求独立RadixTree(更灵活)
- **收益**: n个请求共享prefix → prefix KV只读1次 → 节省(n-1)/n prefix带宽
- 笔记: `vllm-v1-cascade-attention.md`
