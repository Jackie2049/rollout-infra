## 01:20 — vLLM V1 Input Batch + Block Table Source Reading

### 核心

InputBatch = Persistent Batch状态容器 → 1127行 → CPU numpy+GPU双副本+set分类

关键发现:
- **Persistent Batch**: 预分配max_num_reqs行 → 跨step保持 → 只增删变化部分 → ~2x加速
- **Slot-in/Slot-out**: add_request填空slot优先 → remove_request标记None → condense()滑动压缩
- **差量更新**: SamplingMetadata仅在batch变化时重建 → all_greedy跳temperature → no_penalties跳penalties
- **CachedRequestState**: block_ids=tuple[list[int],...] → 多组! → target+EAGLE各有block ids
- **MultiGroupBlockTable**: 多KV cache组 → EAGLE draft自成一组 → 独立block管理
- **7 Triton Kernels**: prefill/pos/seq_lens/draft/rejection/post_update/expand → GPU加速
- **allowed_token_ids_mask延迟分配**: vocab=151K→17.8MB→只在需要时创建
- **Hybrid blocks**: kernel_block_size != alloc_block_size → 展开映射 → MLA用
- **async scheduling**: placeholder=-1 → GPU→CPU异步复制 → event等待 → 修复token ids
