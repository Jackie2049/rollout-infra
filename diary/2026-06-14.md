### 背景

### 核心

Data Pipeline = 数据质量>模型架构 → 质量×3>数量 → curated 5TB≈raw 30TB

关键发现:
- **质量×3>数量**: FineWeb 250B→1.3TB → 8B+FineWeb=70.5% MMLU vs 250B原始=40-50% → 差距20+百分点!
- **DCLM证明**: 同架构不同数据 → 46%→64.8% → 18.8% → 数据决定性! 不改模型只改数据!
- **MinHash LSH去重**: Jaccard阈值=0.7 → k=128 hash → b=16 bands r=8 rows → 去除30-40%近似重复 → 最关键步骤!
- **Quality Filtering**: heuristic(5-10%)+learned classifier(15-25%) → 过滤95% → 5TB高质量 → 多样性保留!
- **DoReMi**: minimax excess loss → L_excess=L_domain-L_ref → 最优domain比例 → 5-10%性能提升 → 不改架构!
- **Data Contamination**: 13-gram overlap检测 → 污染vs投毒(无意vs恶意OWASP#3) → 去污染后真实性能5-10%虚高修正
- **Synthetic Data**: Self-Instruct(Alpaca 52K) + RL自我博弈(R1-Zero/AlphaProof) → 但不能纯合成→model collapse!
- **Data Wall**: 2024-2026人类高质量文本耗尽 → RL自我博弈(有验证器领域)是突破路径 → 无限数据!
- **生产Pipeline**: FineWeb(最严格1.3TB)+DCLM(证明性)+Nemotron-CC(商业30TB)+Datatrove(模块化开源)
- **RTX 4090**: LoRA微调+高质量子集+Self-Instruct+GRPO → 小模型高效路径 → MinHash+quality CPU可行!
